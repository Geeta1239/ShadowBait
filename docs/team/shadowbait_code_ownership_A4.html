shadowbait — Code Ownership Map

Each member works only in their assigned paths. Integrate through shared contracts.

shadowbait/
├── backend/app/   ← Members 1, 2, 3
├── frontend/      ← Member 4
├── demo-site/     ← Member 4
├── evidence/      ← Scanner output
├── tests/         ← Everyone
└── docs/          ← Everyone

Member 1 — Scanner Engineer

Website inspection and evidence collection
  • backend/app/crawler/playwright_engine.py
    Launch Chromium, open URL, handle timeout.
  • backend/app/crawler/dom_extractor.py
    Extract DOM, text, buttons, forms, prices, links.
  • backend/app/crawler/interaction_engine.py
    Read checked, enabled, visible, selected states.
  • backend/app/crawler/page_capture.py
    Capture product, cart, checkout, full-page images.
  • backend/app/crawler/structural_rules.py
    Detect pre-ticked checkbox, timers, scarcity.
  • backend/app/crawler/evidence_writer.py
    Save HTML, JSON, screenshots, selectors, bounding boxes.
Output: scanner JSON + evidence files

Member 2 — Detection Engineer

Rules, NLP, confidence, and pattern classification
  • backend/app/detection/rule_engine.py
    Central DP01–DP05 rule configuration.
  • backend/app/detection/pattern_detector.py
    Convert scanner evidence into findings.
  • backend/app/detection/evidence_engine.py
    Require evidence before verification.
  • backend/app/nlp/preprocessing.py
    Clean and prepare UI text.
  • backend/app/nlp/classifier.py
    Keyword baseline, then DeBERTa.
  • ml/nlp/
    Training/evaluation/inference only if needed.
Output: pattern + confidence + evidence

Member 3 — Backend Engineer

API, orchestration, storage, risk, and compliance
  • backend/app/api/scan.py
    POST /scan and scan status.
  • backend/app/api/results.py
    Return final results and evidence.
  • backend/app/database/
    SQLite models and database access.
  • backend/app/risk/risk_engine.py
    Severity × confidence score.
  • backend/app/compliance/
    CCPA mapping and recommendations.
  • backend/app/reports/
    Report and history output.
  • backend/app/main.py
    Connect API routes and services.
Output: complete API result JSON

Member 4 — Product Engineer

DarkShop, React dashboard, and visual experience
  • demo-site/src/
    Product, cart, checkout, stable element IDs.
  • frontend/src/pages/
    Home, Scanner, Results, Evidence, Reports.
  • frontend/src/components/
    Cards, progress, heatmap, simulator.
  • frontend/src/services/api.js
    Call backend endpoints.
  • frontend/src/hooks/
    Scan status and result state.
  • frontend/src/utils/
    Formatting and display helpers.
Output: live judge-ready product UI
